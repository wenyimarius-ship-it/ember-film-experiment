# 首轮体验改造：代码核查与验收

本次改动：将首页 → 三次选择 → 三片片单，收敛为中文首页 → 点选自动前进 → 单片结果与有依据的一句话 → 确认或换片。验收以真实浏览器流程、原排序回归和首屏可见性为准。

## 依据和范围

已在开发前完整读取《Cinema 电影选择实验 · 产品文档 v1》。该文档明确说明未查看原站的三题和结果；其中对动态页面的推测不作为现状。本记录的现状以 `59e017d52e3b0f3a3baa7c5055a30e6013960e78` 仓库代码为依据。

当前线上域名的只读请求被云环境出站代理以 CONNECT 403 拒绝，因此没有声称已在生产页面完成交互验收。原站源码已经本地检查，改造分支通过本地真实 Chromium 验证。

只修改 Cinema。保留原生 HTML/CSS/JS、深色调、原创几何封面、Ember Lab 固定入口。没有引入 AI、账户、数据库、图片 CDN、外部运行时依赖、真实海报或观看链接。不改生产和域名，不触及其他仓库。

## 原代码核查

- HTML：静态骨架和导航，主要内容由 JS 渲染；原首页并非只有文档看到的页脚标语，实际还有英文大标题、中文说明、开始按钮和原创视觉。
- CSS：深色背景、黄绿色强调、衬线排版、原创 CSS 电影封面、响应式规则和减少动态效果支持。
- JavaScript：原点击选项后需点下一幕；每屏一题，支持上一题、键盘、修改、重新体验、复制及失败回退。
- 数据：16 部真实影片，每部有中英文名、年份、地区、风格、简介、三个维度标签和逐项理由。`js/films.js` 保持字节不变。
- 结果：原版一次展示三部，不是文档提议的单片。
- 数据处理：只有页面内存，无登录、AI、数据库、追踪或对外计算请求。因此页脚“无需登录 · 无 AI · 本地计算”仍属实。

原三个问题和选项，全部保留（`js/questions.js` 字节不变）：

| 问题 | A | B | C |
| --- | --- | --- | --- |
| 面对无法挽回的失败，更想看到人物如何行动？ | 重新建立秩序，夺回主动权。 | 接受无法改变的事实，与过去和解。 | 选择反击，即使付出代价。 |
| 希望故事如何推进？ | 高频冲突、强烈节奏。 | 情绪与人物关系逐渐展开。 | 复杂结构、信息和悬念。 |
| 走到最后，期待什么结局？ | 人物完成改变。 | 不完美但真实、复杂的结局。 | 决定性的冲突、胜负或代价。 |

原算法：标签精确匹配，三维权重 4/3/3；逐次排序中，对已选电影相同风格、地区和年代各减 0.3，最多减 0.9，只调整同分候选；再按原始分和固定 ID 排序。无随机、无评分。测试快照保存原版全部 27 组完整前三名 ID、分数和理由，确保没有改变首选或原三片排序。

## 实际改动

1. 首页中文主标题“今晚想看什么？”、副标题“选三次，找到一部适合此刻的电影。”和“开始选”。英文留在辅助视觉，首页不展示算法或电影清单。
2. 点选立即高亮反馈，80ms（减少动态效果）或 180ms 后前进。锁定连续点击，返回可取消未完成跳转。保留 1/3 进度、上一题、结果页逐题修改和重新体验。
3. 一次展示一部。中文片名优先，保留英文、年份与原基本信息，复用原创 CSS 封面。主理由取最高权重的实际命中偏好和原数据理由，其他实际依据可折叠查看，不暗示命中全部三维。
4. 原 `recommend()` 仍返回相同三部；新增 `candidates()` 以相同评分扩展候选，只保留正分影片。“换一部”按顺序消耗候选，同一次答案完成周期内不重复；耗尽后明确提示并禁用换片。
5. “就看这部”显示“今晚就看这部。”并提供复制片名与理由。复制成功、权限失败、无剪贴板及异步请求期间切换页面均有保护，不显示过期结果。
6. 不使用外部图片，故没有海报授权或加载失败的依赖；测试阻断全部图片请求时封面和电影信息仍正常。CSS 封面为装饰，辅助技术可直接读取真实文字信息。

## 自动化验收

- `npm test`：59 项，覆盖全部 27 组答案、原数据与题目哈希、原始前三名回归、4/3/3、解释、无效输入及有限候选。
- `npm run test:browser`：真实 Chromium，使用既有 Vercel CSP 等安全响应头；遍历全部 27 组答案及每个有效换片候选，检查耗尽不循环；返回修改、确认和复制成功/失败、过期异步复制保护。
- 键盘：A/B/C、1/2/3 直接选择；方向键移动焦点，Enter/Space 确认；Escape 返回；保留原生按钮及可见焦点、题目焦点管理和状态反馈。
- 布局：320 / 375 / 390 / 768 / 1440px，检查首页、每题、结果无横向溢出。375 和 1440px 的首页标题与按钮、结果片名与理由及主操作在 844px 高首屏内。
- 检查减少动态效果、无第三方运行时请求、无页面或控制台错误、双击不跨题。
- 截图见 `docs/screenshots/`，由浏览器测试生成，展示本分支实际页面。截图是本地验收，不冒充 Vercel Preview 截图。
