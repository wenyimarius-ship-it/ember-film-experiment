# Cinema Phase 2C：35部片库接入摘要

推荐池由16部调整为35部已确认入选的电影；版本及现站三维标签逐条核对。暂缓作品不进入推荐池。站点数据仅保留公开展示字段，无豆瓣条目ID、个人评分、观看日期、短评或审核状态。

## 标签约定

定稿代码与现站选项顺序不同。定稿→现站：第一维A/B/C→C/B/A，第二维不变，第三维A/B/C→C/A/B。接入时直接使用已经核对的现站代码，不再转换。例如《降临》定稿BCC→现站BCB，语义为“与过去和解 / 结构与悬念 / 真实与复杂”。

三道题、4/3/3权重、多样性惩罚、同分排序和交互流程保持原样。片库及批准标签变化会改变推荐结果，不应再要求新库结果等同旧16部库。

## 验证范围

- `npm test`：60项全部通过；包含35部版本/标签、字段白名单及27×35=945次分数核对，945次均通过。
- 27组精确10/7/6分计数与审核依据一致；同步映射答案后分布一致。
- 真实Chromium遍历27组全部有效候选：首推与理由、换片去重、候选耗尽停止、返回改选、确认和复制成功/失败均检查。
- 320/375/390/768/1440px布局、键盘、减少动态效果及连续点击保护；检查无控制台/CSP错误、无外部运行时请求。

## 已知覆盖限制

- 有效候选为每组15–32部，但“至少命中一维”不等于全面贴合。
- 定稿ABB / 现站CBA没有10分或7分候选，有4部6分候选：仅后两维命中，不能解释为第一维也命中。
- 12组没有三维全中候选。结果可能因相近标签及固定排序而重复，不表示算法理解了真实心理状态。
- 地区标签为简化分组，非完整合拍国列表；公开简介与匹配理由为编辑文本，本轮没有联网权威资料核验。
- 自动化验收不替代真人观影意愿或首轮体验评估。

逐片验收明细、私人审核文件及本地截图不属于本轮提交范围。本次变更不包含部署配置或生产操作；Draft PR是否触发Preview仍取决于仓库及Vercel项目级集成，不能仅凭Draft状态或本地文件判断。
